# Spacerocks branding

These web assets are optimized derivatives of the confirmed official branding files supplied by Raymond Borges Hink:

- `spacerocks-logo.webp` derives from `OFFICIAL_LOGO_2026SR.png` and is resized to 640 × 640 pixels.
- `spacerocks-banner.webp` derives from `newBanner.png` and retains its 2025 × 777 pixel dimensions.

The source PNG files remain outside the public website repository in the private collection workspace.
